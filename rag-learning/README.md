# RAG Learning: Basic to Advanced

A hands-on learning repository covering Retrieval-Augmented Generation
(RAG), from foundational concepts to advanced and production-ready systems.

## Learning approach

Each phase contains detailed Markdown explanations, runnable Python
examples, exercises, expected outputs, and checkpoints.

## Planned curriculum

- Phase 0: AI, ML, NLP, LLM, and RAG foundations
- Phase 1: Python and data preparation
- Phase 2: Embeddings and semantic similarity
- Phase 3: Vector search and vector databases
- Phase 4: Document ingestion and chunking
- Phase 5: Build RAG from scratch
- Phase 6: RAG with LangChain
- Phase 7: Advanced retrieval techniques
- Phase 8: Advanced RAG architectures
- Phase 9: Evaluation and debugging
- Phase 10: Security, reliability, and deployment
- Phase 11: Capstone project and advanced extensions

## Requirements

- Python
- pip
- Git
- Git Bash or a compatible terminal
- VS Code

Dependencies will be introduced when required by a lesson.

## Security

Never commit API keys, passwords, or real `.env` files.
